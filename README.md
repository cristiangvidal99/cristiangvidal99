### 🐦 Proyecto actual

<strong>BirdWatch Argentina</strong>

Una plataforma web para explorar aves y biodiversidad de Argentina, combinando APIs públicas con información gestionada por la propia aplicación.

El proyecto me permite explorar:

* Datos de biodiversidad y especies
* APIs públicas y datos abiertos
* Datos geográficos y de distribución
* Diseño de APIs REST
* Aplicaciones con React
* Arquitectura backend
* MySQL y modelado de datos
* Desarrollo open source

> Construyendo software alrededor de cosas que realmente me interesan: tecnología, naturaleza y fauna.
